# ☀️ SolarVolt BD — Website

A professional solar consultancy website for **SolarVolt BD**.

## 🚀 Deploy to GitHub Pages (Free Hosting)

### Step 1 — Create GitHub repo
1. Go to [github.com](https://github.com) → **New Repository**
2. Name it: `solarvoltbd` (or anything you like)
3. Set to **Public**
4. Click **Create repository**

### Step 2 — Upload the file
1. Click **"uploading an existing file"**
2. Drag and drop `index.html`
3. Click **Commit changes**

### Step 3 — Enable GitHub Pages
1. Go to repo **Settings** → **Pages**
2. Under "Source" select **Deploy from a branch**
3. Branch: `main` / Folder: `/ (root)`
4. Click **Save**

### Step 4 — Your site is live! 🎉
After ~2 minutes, your website will be at:
```
https://YOUR-USERNAME.github.io/solarvoltbd/
```

## 🎨 Customization
- Edit company phone, email, address in `index.html`
- Change company name from "SolarVolt BD" to your real brand name
- Update pricing in the subscription section
- Add real photos by replacing the animated solar panel illustration

## 📦 Stack
- Pure HTML + CSS + Vanilla JS
- No dependencies, no build step
- Google Fonts (Playfair Display + DM Sans)
- Mobile responsive
- Scroll animations
- Working contact form UI
